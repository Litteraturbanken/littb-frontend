## How to read this ledger

`Shell` answers only whether an Angular URL has a usable Nuxt destination: a page, an intentional canonical redirect, or an intentional external handoff.  It does **not** mean every control, visual state, or data flow inside that page is equivalent.

`Intra-route` records the present parity confidence. `Closed` is backed by the migration closure ledger; `P1` is an identified user-facing loss; `Pending` means a route implementation/test asset is present but no completed closure result is recorded in the shared progress ledger. This makes a reachable route visibly different from a proven equivalent route.

## Deep-parity closure ledger

### Library: `/bibliotek`, `/titlar`, `/epub`, and latest aliases

Library is closed. The shared Nuxt page now covers all Angular modes and facets, filtered author counts, backend-owned chronology, URL push/Back restoration, category/publisher/about-author/narrowing filters, and the native batch source-material download workflow. Duplicate metadata and delimiter-bearing work identifiers fail closed before they can enter predicates or download state. Generic, advanced, download, and standalone EPUB desktop/mobile comparisons are backed by deterministic Angular authority captures.

### Reader: canonical work routes and the Editor Reader

The normal Reader and Editor Reader are closed. The canonical page watches its complete request identity rather than remounting the page, and Nuxt router history preserves each page's horizontal position across page changes and Back/Forward. Läsfokus, night/text-size controls, facsimile OCR, Nya vägar eligibility, typed dictionary lookup, production shortcuts, legacy keyboard controls, and contents/source-information dialogs are present. The Editor branch has bounded sanitized e-text/OCR, typed image data, route-persisted scale/rotation, metadata fallbacks, and real internal navigation. Both surfaces have focused desktop/mobile behavior and deterministic Angular visual gates.

### Bibliographic database: `/författare/:author/biblinfo`

This route is closed after an independent fail-closed review (including strict XML, author-shell error preservation, and conditional audio navigation), with backend v2 1,295/1,295 and all 8 focused SSR/behavior/desktop/mobile checks green. The Angular capture now waits for `ng-hide` animation state to settle before taking the authority screenshot, avoiding a spurious 24px mobile height. The page, capture, and assertion are at [`biblinfo.vue`](../../nuxt/app/pages/författare/[author]/biblinfo.vue), [`capture-author-biblinfo-angular.spec.ts`](../../nuxt/test/visual/capture-author-biblinfo-angular.spec.ts#L160-L193), and [`author-biblinfo.visual.spec.ts`](../../nuxt/test/e2e/author-biblinfo.visual.spec.ts#L29-L47).

## Remaining route work

No Angular route registration remains at P1 in this ledger. Deployment hardening and provider availability are intentionally deferred; the current closure target is local hybrid/SSR parity on the development stack.
